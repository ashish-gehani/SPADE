# Tests

- `MainTest.java` — validates that the shipped default config is valid.
- `setting/ParserTest.java` — required-setting and misconfiguration scenarios for the `mcp.*` keys.
- `tool/ShippedToolConfigsTest.java` — validates that the shipped tool config files under `cfg/mcp/tool/` are valid.
- `tool/registry/RegistryTest.java` — validates that the shipped registry config is valid and loads all the tool configs it links.
