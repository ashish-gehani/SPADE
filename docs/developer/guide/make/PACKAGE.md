# How to Add a Package

Use `pkg/linux/fuse` as the reference implementation. See [`pkg/README.md`](../../../../pkg/README.md) for the conventions it follows (structure, variable naming, build artifacts).

## Files to create

- `configure.ac` — point `AC_CONFIG_AUX_DIR`/`AC_CONFIG_MACRO_DIRS` at the shared root `build-aux`/`m4` dirs (relative path depends on nesting depth); declare every variable needed from the parent via `AC_ARG_VAR`.
- `Makefile.am` — define `all-local`, `clean-local`, `distclean-local`, `maintainer-clean-local`.
- `.gitignore` — lives at the platform level (`pkg/linux/.gitignore`, `pkg/mac/.gitignore`), not per-package.
- `README.md` — document the package and any deviations from the general guidelines.

## Autogenerated files — do not edit

Produced by `autoreconf -fi`: `autom4te.cache/`, `aclocal.m4`, `configure`, `configure~`, `Makefile.in`.

## Registering the package

In the parent platform's `configure.ac`/`Makefile.am` (e.g. `pkg/linux/`):

1. Add detection logic and a conditional `AC_CONFIG_SUBDIRS` for the new package.
2. Add a matching `AM_CONDITIONAL` and update `DIST_SUBDIRS`/`SUBDIRS` in `Makefile.am`.
3. Run `autoreconf -fi` in the new package, then in the platform directory, then at the project root.
